# CLAUDE.md

## 環境

- Docker コンテナの中で動いている。
- 開発サーバーは別のターミナルで起動済み。`npm run dev` は実行しない。
- git は人がパソコン側で使う。git のコマンドは実行しない。

## 作業の約束

- パッケージを追加する前に、名前と理由を伝えて確認を取る。
- 作業が終わったら、変更したファイルを一覧にする。
- 仕様は SPEC.md にある。
- 一度に大きく作らない。SPEC.md の「最初に作るもの」から作り、足したほうがよいものは提案して確認を取る。
- ページのファイルは表示だけにする。判定・計算・データの加工などのロジックは、lib/ に関数として置く。

## 見た目

- 色・角丸は globals.css の変数を使う。
- ボタン・カードなどは _components/ui の部品を使う。

## メモ

- `LayoutProps` などのルート型は、起動中の開発サーバーが `.next/` 以下に自動で生成・更新する。
- テストは未導入。変更後の確認は `npx tsc --noEmit` と `npm run lint` で行う。
